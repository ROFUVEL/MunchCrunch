# MunchCrunch

MunchCrunch — веб-приложение для оформления заказов в сети ресторанов.

Система позволяет клиентам просматривать меню, выбирать ресторан, оформлять заказы и отслеживать их статус. Для сотрудников предусмотрена отдельная панель управления заказами и меню.

## Основные возможности

### Клиент

* Авторизация по номеру телефона и коду подтверждения;
* Выбор точки обслуживания;
* Просмотр меню ресторана;
* Добавление блюд в корзину;
* Оформление заказа;
* Просмотр истории и статусов заказов;
* Просмотр профиля.

### Сотрудник

* Просмотр заказов своего филиала;
* Изменение статусов заказов;
* Управление меню филиала;
* Просмотр информации о своем филиале.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ROFUVEL/MunchCrunch.git
cd MunchCrunch
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка базы данных

1. Установить PostgreSQL.
2. Создать новую базу данных.
3. Выполнить SQL-скрипт создания структуры и начальных данных.

### 4. Настройка подключения

В файле `backend/db.js` указать параметры подключения к PostgreSQL:

* host
* port
* database
* user
* password

### 5. Запуск приложения

```bash
node backend/server.js
```

или

```bash
npm start
```
